# penny-track
PennyTrack 💰

A simple Python Expense Tracker that stores expense records in a CSV file.

Features

- Add expenses
- View all expenses
- Calculate total spending
- Category-wise spending summary
- CSV file storage
- Input validation and exception handling

Technologies

- Python
- CSV File Handling
- Exception Handling

How to Run

python expense_tracker.py

The application provides a menu to add, view, and analyze expenses.

Expense Details

Each record contains:

- Date
- Category
- Amount
- Optional Note

PennyTrack — Track your expenses, one penny at a time. 💸
